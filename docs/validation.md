## E2E 覆盖

1. MV3 Worker、侧栏路径与 IndexedDB 数据表正常；10 位合成人选，3 位初筛通过并深筛，2 位有完整证据后模拟发送。
   两位同名候选人重排后仍按 ID 绑定；系统招呼、HR 消息不算候选人回复；一位候选人回复后打开准确聊天。
2. 发送已发生但回执丢失：UNKNOWN 暂停，禁止直接继续；刷新侧栏保留状态；可靠对账后继续，总发送次数仍为 2。
3. 回执核对后切换岗位：继续被拒绝，不向新岗位串发，发送次数保持为 1。
4. 等待回复时强制终止 Worker：重载后账本与计数保持 2，没有重复发送。
5. 读取详情时强制终止 Worker：恢复为 PAUSED / WORKER_RESTARTED，发送次数为 0；显式继续后完成并仅发送 2 次。

单元测试另覆盖账号切换、页面风险阻断、资料不足、详情错人、暂停停止、CAS、发送中断转 UNKNOWN、
跨任务/跨岗位去重、证据不存在/不完整/身份不符、严格 schema、注入文本及人口属性规则。
这些是有限合成样本结果，不能推导真实平台零错误保证。
