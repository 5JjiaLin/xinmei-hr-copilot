# 页面操作层验证（v0.2）

日期：2026-11-03。当前用户明确公司/招聘账号授权，不以平台许可文件作为此次开发前置。
实现范围是操作层，详细规则后续配置。真实模式不会调用假模型，默认只浏览。

## 实现

- 可选权限仅 `https://www.zhipin.com/*`，由连接按钮请求；不默认注入所有网页。
- 隔离世界 Content Script 通过 DOM 点击/滚动操作，与 MV3 后台通过 tab/frame/document 身份绑定。
- 列表分批发现、稳定 ID 去重，卡片和简历详情身份核验；列表与详情分别滚动；关闭后恢复列表位置。
- 一个任务串行推进。暂停/停止旁路取消页面等待，命令期限 25 秒，身份变化使会话失效。
- MutationObserver 记录身份变更，包含同一事件循环 A→B→A；人工点击/滚轮/键盘介入会让出控制。
- 发送前落账，未知不重发；已经沟通者跳过；成功后关闭详情继续，不等待回复。
- 真实简历只在读取调用内暂存，返回字符数和到底状态，不把全文发送至后台或模型。
- 没有新卡片不等同结束：3 次无进展或 30 次滚动后暂停，只有明确列表结束标识才报结束。

## 真实兼容性边界

**尚未取得用户登录页面的 DOM 观测，不能声称真实 BOSS 已验收。Edge 实机也未验证。**
卡片 ID 属性和 `btn-greet` 仅参考 MIT 项目的代码线索；账号/当前岗位/弹层结构需在当前页面核验。
适配器只接受可核验的 DOM ID 或候选人链接参数，绝不根据姓名、排序或屏幕坐标判断发送目标。
若稳定身份不存在、跨域 iframe 隔断上下文、控件不接受 DOM click，连接诊断会阻止操作；
这些情况需要进一步适配，不能用测试注入的合成 data 属性冒充真实平台支持。

正文“滚到底”是 DOM 几何与稳定时间的观察，不承诺覆盖平台未渲染或隐藏的全部简历信息。
本版不分析录用与匹配；“逐一打招呼”明确作用于整批，不宣称等于未来的规则筛选。
未知招呼只阻断和保留账本，尚未实现真实自动对账或回复接管。
历史 MOCK 演示的迟到请求、回复游标和固定 active 任务问题未在此迭代重构；它们不作为真实操作后端。

## 真实页面验收顺序

1. 构建并加载 `dist`，BOSS 推荐牛人页面选定岗位，点击连接，查看无个人信息的错误码与卡片计数。
2. 先以“只浏览”运行 3 人，验证姓名点击、详情滚动、关闭、列表位置恢复、继续下一位。
3. 验证暂停/继续和人工介入；切岗或刷新后旧动作应失效。
4. 由 HR 明确选择一小批“逐一打招呼”，核对真实平台结果和扩展计数；未知结果不重发。
5. 完成当前 DOM 适配与动作验收后，接入具体初筛/深筛规则及证据结果，不复用 Mock 决策。
